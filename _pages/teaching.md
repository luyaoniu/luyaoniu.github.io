## Teaching

- **TECHIN 509 — Technology Foundation** (Autumn 2024). Fundamental programming skills in Python for software development and data analysis, visualization, and manipulation.
- **TECHIN 512 — Introduction to Sensors and Circuits** (Autumn 2024). Connecting digital systems to the physical world through sensors and microcontrollers; sensor selection and hardware system design.
- **EE 342 — Signals, Systems, and Data II** (Winter 2024). Discrete signal processing: z-transform, DFT, DTFT, and analysis of discrete-time linear systems. Lectures and labs. *Rating: 4.8 / 5.*
- **EE 241 — Programming for Signal and Information Processing Applications** (Spring 2023). Fundamental Python programming in the context of signal and information processing through hands-on projects, with emphasis on writing code that is Functional, Efficient, and Documented. *Rating: 4.5 / 5.*
